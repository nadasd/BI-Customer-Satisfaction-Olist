\# Dataset



This project uses the \*\*Brazilian E-Commerce Public Dataset by Olist\*\*.



The dataset contains information about:

\- Customers

\- Orders

\- Order items

\- Payments

\- Reviews

\- Products

\- Sellers

\- Geolocation

\- Product categories



The dataset was used as the source for the ETL pipeline, PostgreSQL Data Mart,

SQL/OLAP analysis, and Power BI dashboard.



The raw dataset files are not included in this GitHub repository.
